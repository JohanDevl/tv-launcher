# tv-launcher

A custom home screen (launcher) for the living-room Android TV.

## Target device

| | |
|---|---|
| Model | Philips 58PUS7304/12 |
| OS | Android TV 12 (build `STT2.230526.001`, security patch 2025-11-01) |
| Access | ADB over the local network (developer options enabled) |
